# LoRA Ablation Study
This is an ablation study for LoRA

## How to run
To run the experiments, you need to unzip the package from our group chat and add the `./robeata` folder to the root.

If you want to re-run all the experiments, remove the `./outputs` folder. Otherwise, only remove the folder for the particular experiment.

Then run `bash scripts/collect_results.py` at root.
